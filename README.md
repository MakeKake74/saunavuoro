# Saunavuoro - Taloyhtiön Saunanvarausjärjestelmä

Raspberry Pi -pohjainen saunanvarausjärjestelmä Python/Flask-sovelluksella.

## Ominaisuudet

- 📅 Varausten hallinta (1 kk etukäteen, min 2h ennen käyntiä)
- 💰 Dynaaminen hinnoittelu (lämmitys + vesi)
- 👥 Max 30 asukasta
- 🌐 Web-käyttöliittymä
- ⚙️ Konfiguroitavat hinnat (€/kW, €/m³)

## Teknologia

- Python 3
- Flask
- SQLite
- HTML/CSS/JavaScript
